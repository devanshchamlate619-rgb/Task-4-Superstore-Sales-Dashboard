# Superstore Sales & Profit Dashboard

## Task
Data Analyst Internship – Task 4: Dashboard Design

## Objective
Created an interactive Power BI dashboard to analyze sales, profit, orders, and product performance.

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Profit Margin KPI
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Profit by Category
- Top 10 Products by Sales
- Interactive Region, Category and Segment slicers

## Key Results
- Total Sales: 2.30M
- Total Profit: 286.40K
- Total Orders: 5.015K
- Profit Margin: 12.47%
